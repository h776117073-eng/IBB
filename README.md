# سوق إب — IBB Market

منصة عربية RTL للدليل الرقمي والاستكشاف التجاري في مدينة إب. النسخة الحالية **نموذج أولي ثابت** مستضاف عبر GitHub Pages، مع Worker من Cloudflare كواجهة إضافية للـ API. ليست بعد سوقًا إلكترونية متعددة المستخدمين.

## ما هو موجود حاليًا
- واجهة هاتفية عربية للبحث عن أسماء المنشآت والمعالم.
- استيراد **عمود الاسم فقط** من ورقة «الجدول الشامل الكامل (11060)» في ملف Excel المصدر.
- تحميل البيانات عبر 23 ملف JSON لتقليل حجم كل طلب.
- خريطة Leaflet / OpenStreetMap لا تعرض الأسماء المستوردة كعلامات؛ لا توجد إحداثيات في البيانات المستوردة.
- تدفق إضافة المتجر يعرض فحصًا أوليًا للاسم عبر الويب (بحث يدوي إذا لم تُضبط خدمة خلفية)، وخيارات GPS أو لصق إحداثيات Google Maps؛ السجلات الجديدة تبقى محلية وغير موثقة.
- مساعد البحث الحالي مطابقة نصية محلية، وليس نموذج ذكاء اصطناعي مستقلًا.
- فحص نصوص محلي مبدئي يمنع بعض الألفاظ الصريحة والوسوم؛ صور المتاجر والمنتجات الجديدة تبقى مخفية حتى اعتماد الخادم. لا توجد بعد خدمة تحليل صور دلالي أو قاعدة مشتركة فعالة.
- GitHub Actions للنشر إلى GitHub Pages عند التغيير في فرع main.

## حدود البيانات
المصدر “ملف مدينة إب الجديد المحدث (كامل 11060 سجل).xlsx” يحتوي على 11,060 سجلًا، والعمود المستورد هو “اسم المنشأة أو المعلم”. الملف المنشور يتضمن الأسماء فقط، ولا يتضمن العناوين أو الهواتف أو Plus Codes أو الإحداثيات أو التقييمات. وجود الاسم وحده لا يثبت أن السجل متجر عامل أو خالٍ من التكرار؛ لذلك يجب إبقاء الحالة “اسم فقط — غير موثق” حتى تتم المراجعة.

تم تفعيل نطاق Worker على مستوى إعدادات Cloudflare، كما سبق أن أعادت اختبارات التصفح عن بُعد استجابة HTTP 200 للموقع وبياناته. **لكن ذلك لا يثبت أن DNS يعمل على كل شبكة أو هاتف**. إذا ظهر DNS_PROBE_FINISHED_NXDOMAIN، فاعتبر الوصول من تلك الشبكة غير محلول حتى ينجح اختبار فعلي منها.

## كيف تنشر
1. افتح إعدادات GitHub Pages: https://github.com/h776117073-eng/IBB/settings/pages وتأكد أن مصدر النشر هو GitHub Actions.
2. افتح GitHub Actions: https://github.com/h776117073-eng/IBB/actions وتحقق من نجاح أحدث تشغيل للنشر.
3. افتح رابط الموقع على هاتفك، ثم اختبره على بيانات الهاتف وWi-Fi. لا تعتبر النشر ناجحًا للمستخدم النهائي لمجرد نجاح workflow.
4. لا توجد خطوة build مطلوبة للموقع الثابت الحالي.

## ما لم يُنفّذ بعد
- تفعيل قاعدة البيانات المشتركة وتطبيق مهاجرة Supabase بعد إعادة تشغيل المشروع ومراجعة اتصال قاعدة البيانات.
- تسجيل دخول فعلي للتاجر، وواجهة مشرف، وتحقق هوية لا يستطيع العميل تعيينه بنفسه.
- نقطة خلفية للبحث في الويب ومراجعة تلقائية للنتائج؛ البديل الحالي يدوي ولا يُعد بحثًا آليًا.
- خدمة moderation للخادم للنصوص والصور، وتخزين صور خاص، ولا نشر للصورة قبل الموافقة.
- مزامنة المتاجر والإحداثيات والمنتجات بين الأجهزة.
- بحث بصري حقيقي متصل بكتالوج منتجات موثوق.
- طلبات وشراء ودفع وتوصيل حقيقي.
- مزامنة بيانات الخرائط دون اتصال وطبقة خريطة تسمح بالتخزين غير المتصل.
- اختبارات شاملة على أجهزة Android وشبكات مختلفة.
