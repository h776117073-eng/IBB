# سوق إب — IBB Market

منصة عربية RTL للدليل الرقمي والاستكشاف التجاري في مدينة إب، مبنية كـ PWA ثابتة تعمل على GitHub Pages دون تكلفة استضافة.

## ما أُنجز في هذه النسخة

- واجهة هاتفية عربية للاستكشاف والبحث عن أسماء المنشآت.
- استيراد **عمود الاسم فقط** من ورقة «الجدول الشامل الكامل (11060)» في ملف Excel المصدر.
- تحميل البيانات في ملفات JSON مجزأة لتقليل حجم كل طلب.
- خريطة Leaflet / OpenStreetMap؛ لا توضع علامات للأسماء المستوردة لأنها لم تُستورد بإحداثيات.
- يمكن للمستخدم تعيين موقع يدوي على الخريطة، لكن الحفظ في هذه النسخة محلي على الجهاز فقط.
- متابعة الأسماء والإعجاب بالمنتجات المضافة محليًا، مع إخفاء العدادات عن الآخرين.
- إنشاء متجر مجتمعي ومنتجات تجريبية محليًا، دون ادعاء التوثيق أو إرسال طلبات شراء حقيقية.
- إعداد GitHub Actions للنشر إلى GitHub Pages عند الدفع إلى فرع main.

## ملاحظة أساسية عن بيانات المصدر

المصدر يحتوي 11,060 سجلًا وحقولًا إضافية؛ **المستودع يتضمن الأسماء فقط**. لم تُنقل التصنيفات أو العناوين أو الهواتف أو Plus Codes أو خطوط الطول والعرض أو التقييمات أو بقية الأعمدة. واسم العمود الأصلي «اسم المنشأة أو المعلم»، لذلك لا يُعد وجود الاسم وحده دليلًا على أن السجل متجر عامل أو تم التحقق منه. تظهر الأسماء المستوردة على أنها «اسم فقط — غير موثق».

## تشغيل ونشر الموقع

1. افتح Settings → Pages في المستودع، واجعل Source هو GitHub Actions عند الحاجة.
2. سيعمل Workflow المرفق عند الدفع إلى main؛ بعد نجاحه يظهر رابط Pages في صفحة Actions أو Settings → Pages.
3. لا يحتاج المشروع إلى build step أو مفاتيح API مدفوعة. الخريطة تعتمد على Leaflet وطبقات OpenStreetMap عبر الإنترنت.

## حدود النسخة الحالية

هذه نسخة واجهة أولية قابلة للتجربة وليست منصة إنتاجية متعددة المستخدمين بعد. البيانات التي يُدخلها المستخدم تُحفظ في localStorage على جهازه فقط. لا يوجد بعد خادم أو قاعدة بيانات مشتركة، أو تسجيل دخول، أو توثيق هوية/ملكية، أو لوحة إدارة مؤمنة، أو رفع صور سحابي، أو OCR، أو نموذج ذكاء اصطناعي مستضاف ذاتيًا، أو دفع/توصيل/تنفيذ طلبات حقيقية. لا تُدخل مستندات هوية أو بيانات مالية في هذه النسخة.

## الهيكل

- `index.html`: الواجهة والتفاعلات.
- `data/index.json`: فهرس ملفات الأسماء.
- `data/store-names-*.json`: قوائم JSON، كل عنصر فيها نص اسم فقط.
- `manifest.webmanifest` و`sw.js`: أساسيات PWA.
- `.github/workflows/pages.yml`: النشر.
