# إثراء دليل مدينة إب عبر GitHub Actions

هذا المسار يبني ملفات بيانات قابلة للتنزيل من مستودع IBB، ولا يعدّ الناتج تعداداً رسمياً أو قائمة مكتملة مؤكدة.

## ما يجمعه التشغيل

1. يقرأ أسماء السجلات الأصلية من ملفات data/store-names-*.json، ويتحقق من العدد المسجل في data/index.json.
2. يقرأ بذرة الدليل العام البالغ عددها 270 سجلاً، مع إبقاء اسم المصدر وحالة التحقق ورابطه. تُفك رموز Plus Codes القصيرة إلى إحداثيات بالاستناد إلى مركز تقريبي لمدينة إب؛ لذلك يلزم فحص المواقع.
3. يستعلم من OpenStreetMap / Overpass عن العناصر المسمّاة ذات وسوم الأنشطة داخل مستطيل جغرافي تقريبي. حدود المستطيل ليست حدوداً إدارية معتمدة.
4. عند وجود مفتاح نموذج لغوي، يشغّل ScrapeGraphAI على صفحات أدلة عامة لاستخراج الأسماء والتفاصيل الظاهرة فقط.
5. ينتج قائمة مرشحات مطابقة بين الأسماء وبيانات OSM، من دون دمج تلقائي؛ قد تتشابه أسماء الفروع أو الأنشطة المختلفة.

## تشغيل يدوي

افتح GitHub Actions ثم اختر **Enrich Ibb establishment directory** ثم **Run workflow**.

## أسرار ScrapeGraphAI

- أضف SCRAPEGRAPH_API_KEY إلى Repository secrets، أو استخدم OPENAI_API_KEY الموجود أصلاً.
- يمكن ضبط متغير Repository variable باسم SCRAPEGRAPH_MODEL. القيمة الافتراضية هي openai/gpt-4o-mini.
- لا تضع أي مفتاح في الملفات أو في المحادثة. تثبيت ScrapeGraphAI وChromium مشروط بوجود المفتاح.

## الرفع التلقائي إلى Google Drive

الرفع لا يعمل إلا بعد إعداد حساب خدمة Google Drive ومشاركة مجلد Drive معه بصلاحية محرر، ثم إضافة Repository secrets التالية:

- GDRIVE_SERVICE_ACCOUNT_JSON: محتوى ملف JSON لحساب الخدمة.
- GDRIVE_FOLDER_ID: معرّف مجلد Drive الوجهة.

لا ترفع ملف JSON لحساب الخدمة إلى المستودع ولا ترسله في المحادثة. إذا لم توجد الأسرار، يظل ملف ZIP متاحاً في GitHub Actions artifact باسم ibb-directory-export.

## الملفات الناتجة

- ibb_source_names_11060.csv: جميع الأسماء الأصلية، مع وسم واضح بأنها أسماء غير موثقة.
- ibb_public_directory_seed.csv: سجلات الدليل العام المصدرية مع الإحداثيات المفكوكة عند وجود Plus Code.
- ibb_osm_businesses.csv: عناصر الأنشطة المسمّاة من OpenStreetMap وإحداثياتها.
- ibb_scrapegraph_candidates.csv: ما يستخرجه ScrapeGraphAI عند تهيئة مفتاح نموذج.
- ibb_name_match_candidates.csv: اقتراحات مطابقة تتطلب مراجعة بشرية.
- ibb_all_sources_full.csv: ملف موحد يحافظ على نوع السجل والمصدر وحالة التحقق.
- summary.json وREADME.txt: أعداد التشغيل وحدوده وملاحظاته.

## حدود الجودة

الأسماء الـ11,060 لا تحتوي في المصدر الأصلي على العناوين أو الهواتف أو الإحداثيات. نتائج الأدلة العامة وOSM لا تثبت أن النشاط ما زال مفتوحاً. كما لا يمكن ضمان الحصر الكامل لكل منشآت المدينة من صفحات الإنترنت أو بيانات الخرائط وحدها. لا تدمج السجلات ولا تعرضها كمنشآت مؤكدة قبل التحقق من المصدر/الفرع/الموقع. ملف CSV سابق بنحو 9,000 صف مستبعد لأنه أظهر أنماط أسماء وإحداثيات اصطناعية ومتكررة.
