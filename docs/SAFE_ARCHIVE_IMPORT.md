# استيراد آمن لأرشيف خرائط Google — 7,015 سجلًا

## حدود المصدر

- بيان المصنف يحمل الاسم التعريفي `السجل الجديد المتحقق منه عبر خرائط جوجل.xlsx` في `sourceWorkbook`.
- كل سجل مرحلي يحمل `source_file=verified_ibb_registry.xlsx`؛ يسجل البيان هذه القيمة منفصلة في `stagedRowSourceFile`. هذان الحقلان تسميتان منفصلتان؛ لا ندّعي أنهما ملفان متطابقان بايتًا ببايت.
- يقبل Worker قيمة السجل المرحلي `verified_ibb_registry.xlsx` فقط، ويشترط مصدر `GOOGLE_MAPS_ARCHIVE_WORKBOOK`.
- قائمة السماح هي ورقة الأسماء الموحدة: 7,015 صفًا / 7,015 Place IDs.
- ورقة السجلات الخام البالغ عددها 16,441 صفًا تُحصى في البيان فقط؛ يجب أن تبقى `rawSheetRecordsImported=0`.
- كل صف جديد يبقى `identity_status=UNVERIFIED` و`verification_status=UNVERIFIED` و`visibility_status=NEEDS_REVIEW` و`is_public=0`.
- لا يثبت Place ID أو عنوان الأرشيف أن المنشأة مفتوحة أو أن ملكيتها موثقة أو أن موقعها دقيق.

## آلية الحماية

يقبل Worker المسار الإداري `POST /api/v1/admin/directory/archive-import` فقط مع سر `IMPORT_API_KEY`، أو `ADMIN_API_KEY` في الإنتاج عند عدم وجود سر استيراد مخصص. يتحقق من مصدر السجل، والاسم المرحلي، وتطابق معرّف السجل تشفيريًا مع Place ID، وحالة المراجعة وتسلسل الصف والإحداثيات.
قبل كل دفعة، يقارن Worker المعرّفات ومفاتيح (اسم المصدر، رقم صف المصدر) مع D1. إذا تطابق المعرّف وPlace ID ورقم الصف، يتخطى السجل دون تحديث؛ وإذا اختلف ارتباط رقم الصف أو Place ID، يرفض الدفعة كلها قبل أي كتابة. كما يحصي الحالات التي اختلف فيها source_hash دون استبدال السجل الموجود. حجم الدفعة الأقصى 250 صفًا. يستخدم الإدراج فقط مع `ON CONFLICT DO NOTHING` لتغطية أي تعارض متزامن بعد الفحص.

## الاستخدام

من جذر المستودع:

```bash
# فحص كامل لجميع الشظايا دون أي كتابة على D1
python scripts/import_google_maps_archive.py

# عند اتخاذ قرار مستقل ومصرح به للكتابة الحية:
IBB_IMPORT_API_KEY=... python scripts/import_google_maps_archive.py --apply --confirm-count 7015
```

الوضع الافتراضي دائمًا هو dry-run. التنفيذ الحي يحتاج إلى `--apply` و`--confirm-count 7015` ومفتاح `IBB_IMPORT_API_KEY`. لا ينفذ CI أو فتح PR أي كتابة على قاعدة البيانات. إذا توقفت دفعة، يعاد تشغيل الأمر نفسه؛ المعرّفات الموجودة تُتخطى ولا تُحدّث.

## القيود الحالية

- هذا التغيير يضيف المسار والأداة والاختبارات فقط؛ لا ينفذ استيرادًا مباشرًا ولا ينشر Worker.
- يجب نشر نسخة Worker التي تحتوي endpoint قبل استخدام وضع `--apply`.
- Worker التجريبي مربوط حاليًا بقاعدة D1 نفسها المستخدمة في الإنتاج؛ لذلك لا يُعامل كبيئة بيانات معزولة ولا يستخدم لاختبارات كتابة.
- حدود D1 اليومية قد توقف الاستيراد؛ عندها يوقف السكربت التنفيذ ويكون الاستئناف آمنًا في تشغيل لاحق.
- لا يدمج هذا المسار مجموعة السجلات الخام أو ملف المراجعة المنفصل ذي 11,060 سجلًا.
