## ضوابط الاستيراد

- المستورد يقبل 7,015 صفًا فقط، بعد التحقق من كل الشظايا ومن اكتمال تسلسل الصفوف.
- يستبعد ورقة السجلات الخام 16,441 نهائيًا من مسار الاستيراد.
- كل سجل جديد يبقى `UNVERIFIED` و`NEEDS_REVIEW` و`is_public=0`.
- يُقارن Worker هوية السجل ورقم الصف وPlace ID مع السجلات الموجودة قبل أي إدراج.
- التطابق التام يُتخطى دون تعديل؛ اختلاف هوية صف المصدر أو Place ID يوقف الدفعة كلها.
- لا يستخدم الاستيراد `UPDATE` عند التعارض؛ يستخدم إدراجًا فقط مع `ON CONFLICT DO NOTHING`.
- لا يُحوّل أي سجل إلى `VERIFIED_MATCH` ولا إلى `PUBLISHED` تلقائيًا. Place ID أو وجود السجل في الأرشيف لا يثبت مراجعة مستقلة، ولا يثبت أن النشاط ما زال يعمل أو أن ملكيته موثقة.
- Worker التجريبي مربوط بقاعدة D1 الإنتاجية نفسها؛ لا يستخدم لإجراء اختبارات كتابة.
