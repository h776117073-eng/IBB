# المرحلة الأولى: الدليل المشترك والمراجعة

- قاعدة D1 مشتركة للمنشآت والمنتجات والطلبات وسجل المراجعة.
- Worker منفصل عن Worker الرفع الحالي.
- قراءة عامة للسجلات المعتمدة فقط؛ الإرسال الجديد يبدأ Pending.
- إرسال الموقع أو المنتج اختياري وصريح، مع Idempotency UUID.
- حد يومي أولي للمساهمات وبصمة SHA-256 للاتصال بدل حفظ عنوان IP الخام.
- لوحة إدارة منفصلة بمفتاح سري لا يُخزن في Git أو localStorage.
- الأسعار في المرحلة الأولى بالريال اليمني YER؛ لا مدفوعات ولا Escrow.

اعتماد سجل الدليل لا يثبت ملكية المتجر أو ترخيصه. تبقى الأسماء المستوردة أسماء فقط.

لم تنفذ بعد الحسابات وOTP والتحقق من الملكية والطلبات والدفع والتوصيل الحي والسائقين والذكاء الاصطناعي وKafka وRedis وgRPC وKubernetes. هذه تتطلب خدمات واعتمادات واختبارات فعلية.

للتشغيل المحلي: من worker نفّذ npm install ثم npm test وnpm run check. اضبط ADMIN_API_KEY باستخدام wrangler secret put. قاعدة البيانات تستخدم migrations/0001_shared_directory.sql.
