# خريطتي لمحافظة إب — المنصة الجيومكانية والتجارية المتكاملة (`Ibb GeoPlatform Enterprise v3.0`)

منصة خرائط رقمية وملاحة ودليل تجاري متكامل خاصة بمحافظة إب، مصممة ومملوكة بالكامل للمشروع بهوية مستقلة (`خريطتي • إب PRO`) دون أي تبعية لبلاطات خرائط تجارية خارجية، وجاهزة للعمل التجاري والدمج المباشر مع تطبيقات التوصيل والمتاجر الإلكترونية والأنظمة المحاسبية وتطبيقات الهواتف الذكية (`PWA / Android APK / Capacitor`).

- **الرابط الحي للتطبيق (Live Enterprise PWA)**: [https://mhommdkuyr.github.io/my-ibb-governorate-map/](https://mhommdkuyr.github.io/my-ibb-governorate-map/)
- **المستودع الرسمي**: [https://github.com/mhommdkuyr/my-ibb-governorate-map](https://github.com/mhommdkuyr/my-ibb-governorate-map)

## 1. البنية المعمارية المملوكة (6 طبقات هندسية متكاملة)

1. **قاعدة البيانات الجيومكانية الموحدة لمحافظة إب**:
   - **`444,968` مضلع مبنى ثلاثي الأبعاد (`3D Buildings`)** بارتفاعات وبثق هندسي حقيقي (`fill-extrusion`) وإسناد مكاني للمتاجر داخل المباني (`Point-in-Polygon Building Binding`).
   - **`13,125` مقطع طريق موجه** يغطي الشرايين الرئيسية، الشوارع التجارية، الأزقة، والأزغطة التاريخية في كافة مديريات محافظة إب الـ 20.
   - **`57,556` منشأة ومعلم وتجمع سكني** تشمل `44,273` منشأة مصنفة عبر 29 قطاعاً و`10,814` منشأة ومعلم موثق تفصيلياً بالحارة والشارع والطوابق والارتفاع والهاتف والتقييم ورموز `Plus Codes`، و`12,788` قرية وتجمعاً سكنياً.
2. **عزل الخيوط الخلفية (`Web Workers Architecture`)**:
   - `js/ibb-search-worker.js`: فهرس نصي مقلوب (`Inverted Index`) مع التطبيع العربي الشامل (`normalizeArabicQuery`)، وفهرس مكاني ثنائي (`Float64Array Spatial Index`)، وتوليد رموز `Plus Codes` (`Open Location Code`) محلياً بسرعة استجابة `< 1 ms` دون حجب خيط الرسم الرئيسي (`60 FPS`).
   - `js/ibb-routing-worker.js`: محرك توجيه وملاحة محلي 100% بدون إنترنت (`MinHeap` + خوارزمية `A*` الموزونة بالزمن والانحدار الجبلي وسرعات الشوارع) يعمل على ملف `data/ibb_routing_graph.json` (`1,422` عقدة تقاطع و`9,096` حافة موجهة) مع تعليمات الملاحة العربية خطوة بخطوة (`Turn-by-Turn`) والنطق الصوتي (`Web Speech API`) وحاسبة رسوم التوصيل بالريال اليمني.
3. **التخزين الذكي دون اتصال (`IndexedDBByteSource` لبروتوكول `PMTiles`)**:
   - حفظ شرائح البلاطات الثنائية (`ArrayBuffer`) المقروءة عبر طلبات النطاق الجزئية (`HTTP 206 Range Requests`) مباشرة داخل `IndexedDB` (`ibb_pmtiles_range_cache_v3`) مع تفعيل حماية الكاش الدائم `navigator.storage.persist()`.
4. **التضاريس الجبلية الثلاثية الأبعاد (`3D Terrain DEM`) والأنماط البصرية**:
   - تجسيد جبال ووديان محافظة إب الحقيقية (`1,500m – 2,800m`) عبر بلاطات `Terrarium DEM` مع ظلال التلال (`hillshade`)، وأربعة أنماط عرض مستقلة: **خريطتي 3D النهارية**، **النمط الليلي 3D الذكي**، **القمر الصناعي المداري + 3D**، و**تضاريس إب الجبلية 3D**.
5. **عارض التجول الميداني 360° (`Ibb Street-Level & Storefront Viewer`) والمساعد الذكي (`Geo-RAG`)**:
   - معاينة ميدانية تفاعلية بزاوية `360°` للشوارع والمعالم الحيوية (شارع العدين، جولة العدين، المدينة القديمة، شارع الثلاثين) مع ربط الواجهات التجارية، ومساعد ذكي (`Geo-RAG`) يجيب على الاستفسارات المكانية والتجارية بلغة عربية طبيعية.
6. **حزمة التكامل التجاري للمطورين (`sdk/ibb-map-sdk.js`)**:
   - واجهة `window.IbbMapSDK` وبروتوكول `postMessage` لربط الخريطة فوراً مع تطبيقات التوصيل، المتاجر الإلكترونية، وأنظمة إدارة المنشآت.

## 2. الاستخدام التجاري والدمج البرمجي السريع (`IbbMapSDK`)

```javascript
// 1. البحث عن منشأة أو متجر في محافظة إب
const results = await window.IbbMapSDK.searchPlaces('مستشفى في الظهار', { limit: 10 });

// 2. حساب مسار التوصيل وتكلفة التوصيل التقديرية (بدون إنترنت عبر A* Worker)
const route = await window.IbbMapSDK.calculateDeliveryRoute(
  { lat: 13.97265, lng: 44.16155 }, // جولة العدين
  { lat: 13.96850, lng: 44.15650 }, // شارع الثلاثين
  'driving'
);
console.log(route.distanceMeters, route.estimatedDeliveryFeeYER, route.steps);
```
