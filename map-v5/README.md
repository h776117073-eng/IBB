# IBB Market Geo-Engine v5 — نسخة مرحّلة داخل مشروع إب ماركت

هذه النسخة تنقل محرك العرض والبحث العربي المحلي والتوجيه المحلي وبيانات الخريطة من المستودع المصدر إلى المسار `/map-v5/` داخل مشروع `h776117073-eng/IBB`. المسار القديم `/map/` يبقى كما هو.

## ما يتضمنه هذا النقل

- واجهة MapLibre GL JS وPMTiles، مع طبقات المباني والطرق والحدود والأماكن والتضاريس.
- عامل بحث عربي محلي وملفات بيانات JSON وشظايا المديريات والمدن.
- عامل توجيه محلي يعتمد على رسم الطرق الموجود في `data/ibb_routing_graph.json`.
- تخزين مؤقت لطلبات PMTiles الجزئية داخل IndexedDB.
- زر ربط المكان المحدد بدليل إب ماركت: يستعلم من Worker المشروع باستخدام الاسم ونطاق إحداثي ضيق، ولا يفتح صفحة المكان إلا عند وجود تطابق قريب منشور.
- اختبارات وحدة البحث والتوجيه واختبارات تكامل المشروع.

## حدود النسخة المرحّلة

- ملفات PMTiles الثنائية لم تُنسخ إلى Git لتجنب إضافة نحو 153 MB إلى تاريخ المستودع. يقرأ العارض البلاطات مؤقتاً من مستودع المصدر العام: `https://mhommdkuyr.github.io/my-ibb-governorate-map/pmtiles`. يجب نقل هذه الأرشيفات إلى تخزين IBB Market أو Cloudflare R2 وتحديث `PM_BASE` قبل اعتبار النشر مستقلاً.
- تم استبعاد وحدات API والمتاجر التجريبية من المصدر، كما تم تعطيل عنوان ومفتاح مشروع Supabase الخارجي. لا توجد في هذه النسخة بيانات اعتماد أو اتصال بقاعدة Supabase المصدر.
- زر فتح صفحة المتجر لا يخمّن المتجر ولا يفتح أول نتيجة؛ إذا لم يجد سجلاً منشوراً مطابقاً ضمن 120 متراً يعرض رسالة ولا ينتقل.
- المساهمات في هذه النسخة محلية وقابلة للتصدير والمراجعة، وليست بعدُ إرسالاً دائماً إلى خادم المشروع.
- إذا لم يجد محرك A* مساراً صالحاً في شبكة الطرق، يعرض عدم توفر المسار بدلاً من رسم خط مستقيم مصطنع.
- صور عارض الشارع المرفقة مواد مرجعية للواجهة، وليست تغطية ميدانية كاملة أو خدمة Street View موثقة.
- الأنماط القمرية والتضاريس تعتمد على مصادر بلاطات خارجية، وتحتاج مراجعة الأداء والتوفر في الشبكات الضعيفة.

## التشغيل والاختبار

- افتح `/map-v5/` من الصفحة الرئيسية للمشروع.
- شغّل `node map-v5/tests/run_tests.js` لاختبارات البحث والتوجيه.
- شغّل `node map-v5/scripts/validate-v5.mjs` لفحص ملفات البيانات وربط دليل إب ماركت.
- Workflow `.github/workflows/geo-engine-v5-import-and-test.yml` يشغّل أيضاً اختبارات واجهة إب ماركت وWorker الحالي.

## قرار الدمج

هذه النسخة جاهزة للمراجعة والدمج كمسار تجريبي معزول فوق فرع خريطة Overture، وليست إعلاناً عن اكتمال كل وظائف خرائط Google أو جاهزية تشغيل تجاري مستقل. شرط إغلاق الدمج الإنتاجي هو نقل PMTiles إلى تخزين المشروع، والتحقق من الربط مع سجلات المتاجر الفعلية، واختبار المتصفح على الاستضافة النهائية.
